Channel status offline

Connect to load the live manifest.

2 · Build a release delta

3 · Signing key RSA-2048

Manifests are signed (SHA256withRSA). The app only accepts manifests whose manifest.sig verifies against the public key baked into the APK.

Generating a NEW keypair invalidates all previously installed shells — you must embed the new public key (below) into UpdateKeys.kt and ship a new APK.

4 · Publish

Uploads manifest.json, manifest.sig and every changed file to the update repo. Devices pick it up on next launch / background check and download only the changed files.

5 · Ship a new APK shell optional

Only needed when native Kotlin code changes. Creates a GitHub Release on the update repo with the APK as a public asset; then set min shell version above to that versionCode so apps force-upgrade.
